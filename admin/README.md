# Lumière admin app

React + Vite + TypeScript staff portal. Start with `npm install`, configure `.env` from `.env.example`, then `npm run dev`.

Current working scope: Supabase Auth sign-in, role-aware data access enforced by database RLS, lead dashboard/list, realtime lead refresh, status updates, manual lead creation, quick contact actions, search/filter, and theme toggle.

Not yet implemented in this version: full calendar/drag rescheduling, follow-up CRUD, complete content-manager forms, settings editor, user invitation/role management UI, analytics exports, patient portal, full command palette, and production accessibility/security audit. Do not describe this scaffold as production-complete until these are built and tested.
